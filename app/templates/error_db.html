{% if cat == 'auth' or 'authentication' in (error_details or '')|lower or 'password' in (error_details or '')|lower or 'invalid_uri' == cat %}

🔐 Password Encoding & Database User Credentials

  1. In MongoDB Atlas, open Security → Database Access and verify your database username and password.
  2. Make sure you replaced placeholders like <password> in .env with your real password.
  3. If your password contains special characters (@ : / ? # [ ] %), URL-encode it with Python: python -c "import urllib.parse; print(urllib.parse.quote_plus('YOUR_PASSWORD'))"
{% elif cat == 'dns_srv' or 'srv' in (error_details or '')|lower or 'dns' in (error_details or '')|lower %}

🌐 DNS SRV Lookup Resolution

  1. Your network or ISP DNS server failed to resolve the mongodb+srv:// record.
  2. Set MONGODB_DNS_SERVERS=8.8.8.8,1.1.1.1 in .env or change your Windows adapter DNS to Google (8.8.8.8) / Cloudflare (1.1.1.1).
  3. Alternatively, in Atlas click Connect → Drivers and copy the standard (non-SRV) connection string (mongodb://host1:27017,host2:27017,...).
{% elif cat == 'tls' or 'tls' in (error_details or '')|lower or 'certificate' in (error_details or '')|lower %}

🛡️ TLS / SSL Certificate Handshake

  1. Ensure the certifi package is installed and up to date (pip install -U certifi).
  2. Check that your system clock/date is accurate and no antivirus or corporate proxy is intercepting TLS traffic on port 27017.
{% else %}

🛡️ Atlas Network Access IP Whitelist

  1. Log in to your MongoDB Atlas Console.
  2. In the left sidebar under Security, click Network Access.
  3. Click the green "Add IP Address" button and choose "Add Current IP Address" (or 0.0.0.0/0 for testing).
  4. Click Confirm and wait ~30–60 seconds for Atlas to deploy the firewall rule.
{% endif %}
